## C. Professional LinkedIn project description
I built a cloud-connected smart plant monitoring and automated watering
system as a cloud computing project. Soil moisture, temperature, humidity
and light readings are ingested through a secured REST API, stored in a
cloud database, and evaluated by an automated watering engine with
overwatering safeguards (cooldown periods and maximum watering duration).
A React dashboard shows live plant status, historical trends, and alerts,
with support for manual watering and per-plant thresholds. The entire
system runs on a realistic Python IoT sensor simulator — no physical
hardware required — and the same architecture accepts a real ESP32 device
without any backend changes. The project is fully tested (25 automated
scenarios), containerizable, and deployed on free-tier cloud
infrastructure with CI via GitHub Actions.
